# Pico2_encoder_PIO — цифровой отсчёт (ДРО) на Raspberry Pi Pico 2

Проект DRO (digital readout) для оси станка: квадратурный энкодер декодируется
аппаратно на PIO (state machine RP2350), счёт копируется на CPU через DMA,
позиция выводится в миллиметрах на LCD 1602 по I2C, диагностика идёт в USB-консоль.
Использовать как пример для своих доработок! Вариаций множество!

## Возможности

- Квадратурный декодер x4 полностью на PIO: ни одного отсчёта не теряет при
  системной частоте 150 МГц (запас по скорости — десятки МГц фронтов).
- Счётчик живёт в регистре X state machine, CPU его не опрашивает —
  DMA непрерывно сливает актуальное значение из RX FIFO в память.
- Метка Z (референс, 1 на оборот) обрабатывается прерыванием с двумя
  программными фильтрами: временным антидребезгом (1 мс) и квадратурным
  барьером «пол-оборота счётчика» — дребезг не проходит в счёт.
- Вывод позиции в мм с точностью 1 мкм на LCD 1602 по I2C (PCF8574, адрес 0x27).
- Диагностика по USB CDC: счётчик, позиция, счёт Z, направление.

## Подключение

| Сигнал | Пин Pico 2 | Примечание |
|--------|------------|------------|
| A      | GP2        | подтяжка к питанию включена в прошивке |
| B      | GP3        | подтяжка к питанию включена в прошивке |
| Z      | GP7        | референсная метка, подтяжка к питанию |
| GND    | GND        | общая земля обязательна |
| SDA    | GP4        | LCD 1602 (PCF8574) |
| SCL    | GP5        | LCD 1602 (PCF8574) |

Если у вас другие пины — поменяйте `ENC_A_PIN` / `ENC_B_PIN` / `ENC_Z_PIN`
в `encoder.h` и `LCD_SDA` / `LCD_SCL` в `lcd_i2c.c`.

## Настройка под свой станок

В `encoder.h`:

- `ENC_COUNTS_PER_REV` — отсчётов декодера на один оборот вала (CPR).
- `ENC_PITCH_UM` — ход винта в микрометрах на оборот.

Позиция считается как `counts * PITCH_UM / COUNTS_PER_REV`.

## Сборка (Windows)

Нужны: CMake >= 3.13, Ninja, GCC ARM None EABI, pico-sdk
(переменная окружения `PICO_SDK_PATH`).

```powershell
cd Pico2_encoder_PIO
cmake -B build -G Ninja -DPICO_BOARD=pico2
cmake --build build
```

Результат: `build/Pico2_encoder_PIO.uf2`.

## Прошивка

1. Зажмите BOOTSEL на Pico и подключите USB.
2. Скопируйте `Pico2_encoder_PIO.uf2` на появившийся диск `RP2350`.
3. Откройте COM-порт устройства (например, PuTTY, 115200) — каждые 0.5 с
   печатается строка диагностики. PuTTY открывать как **Serial, скорость 115200** — на Windows.

## Как это работает (коротко)

Декодер `encoder.pio` — таблица переходов на 16 инструкций: индекс —
`(предыдущее состояние << 2) | текущее`, где биты пары: старший — канал A,
младший — канал B. Невозможные переходы (изменились оба бита сразу — глитч)
возвращают машину на `start` без изменения счётчика. Прямые переходы дают
±1, счётчик — регистр X, каждое изменение выталкивается в RX FIFO (`push noblock`)
и забирается DMA.

Программа обязана начинаться с адреса 0 (`.origin 0`) — прыжок по индексу
выполняется через `mov pc, isr` и идёт в абсолютный адрес.
